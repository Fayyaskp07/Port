Pizza Sales Analysis

Data Analytics Project

  1. Home
  2. Pizza Sales Analysis

In today’s data-driven world, understanding customer behavior and sales trends is vital for success, especially in the competitive food industry. This project analyzes pizza sales data using SQL to uncover key metrics such as top-selling pizzas, peak order times, and revenue patterns. The findings are visualized through an interactive Power BI dashboard, showcasing how raw data can be transformed into actionable business insights using data analysis and BI tools.

Tools & Technologies Used

  • SQL – Data cleaning, transformation, metric calculation
  • Power BI – Data visualization, dashboard design, KPI tracking
  • Microsoft Word – Insight documentation and reporting

Project Objectives

  • Clean and preprocess raw pizza sales data using SQL
  • Analyze customer purchase behavior, sales trends, and product performance
  • Identify high-performing and underperforming pizzas
  • Visualize insights through an interactive Power BI dashboard
  • Provide actionable business recommendations

Problem Statement

To help a pizza restaurant business optimize its operations and increase profitability, this project focuses on analyzing pizza sales data to extract insights on sales performance, customer behavior, and popular product categories. Using SQL and Power BI, we aim to answer key business questions through structured analysis and visualization.

KPI Requirements

  • Total Revenue
  • Average Order Value
  • Total Pizzas Sold
  • Total Orders
  • Average Pizzas per Order

Charts Requirement

  • Daily Trends for Total Orders
  • Monthly Trends for Total Orders
  • % of Sales by Pizza Category
  • % of Sales by Pizza Size
  • Total Pizzas Sold by Pizza Category
  • Top 5 Pizzas by Revenue, Quantity, and Orders
  • Bottom 5 Pizzas by Revenue, Quantity, and Orders

SQL Queries Used

Click to expand SQL Queries 

-- View all records
SELECT * FROM pizza_sales;

-- 1. Total Revenue
SELECT SUM(total_price) AS Total_Revenue FROM pizza_sales;

-- 2. Average Order Value
SELECT SUM(total_price) / COUNT(DISTINCT order_id) AS AVG_Order_Value FROM pizza_sales;

-- 3. Total Pizzas Sold
SELECT SUM(quantity) FROM pizza_sales;

-- 4. Total Orders
SELECT COUNT(DISTINCT order_id) AS Total_Orders FROM pizza_sales;

-- 5. Average Pizzas per Order
SELECT CAST(CAST(SUM(quantity) AS DECIMAL(10,2)) / 
CAST(COUNT(DISTINCT order_id) AS DECIMAL(10,2)) AS DECIMAL(10,2)) AS Avg_Pizzas_per_Order
FROM pizza_sales;

DAX Queries Used

Click to expand DAX Queries 

-- Total Revenue
Total Revenue = SUM(pizza_sales[total_price])

-- Total Pizzas Sold
Total Pizzas Sold = SUM(pizza_sales[quantity])

-- Total Orders
Total Orders = DISTINCTCOUNT(pizza_sales[order_id])

-- Avg Pizzas Per Order
Avg Pizzas Per Order = [Total Pizzas Sold] / [Total Orders]

-- Avg Order Value
Avg Order Value = [Total Revenue] / [Total Orders]

Calculated Column Measures

-- Order Day Abbreviation
Order Day = UPPER(LEFT(pizza_sales[Day Name], 3))

-- Order Month Abbreviation
Order Month = UPPER(LEFT(pizza_sales[Month Name], 3))

Business Outcomes

  • Identified peak order times: Weekends, especially Friday/Saturday evenings
  • Monthly peaks in January and July
  • Classic category dominates sales and orders
  • Large-size pizzas generate most revenue
  • Thai Chicken Pizza: Top revenue generator
  • Classic Deluxe Pizza: Highest in orders and quantity sold
  • Brie Carre Pizza: Lowest in all performance metrics

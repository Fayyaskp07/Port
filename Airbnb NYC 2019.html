Airbnb NYC 2019

Data Analytics Project

  1. Home
  2. Airbnb NYC 2019

Overview

This Airbnb 2019 Tableau Dashboard provides insights into Airbnb listings in New York City, leveraging Tableau to analyze key metrics such as pricing trends, availability, and listing distribution. The goal is to uncover patterns in Airbnb listings to assist hosts, travelers, and policymakers in making informed decisions. Key focus areas include:

  • Listing distribution by neighborhood
  • Price variation across boroughs
  • Room type analysis
  • Availability trends
  • Host activity insights

Problem Statement

Analyze Airbnb listings in NYC and build an interactive Tableau dashboard to help users understand pricing trends, availability, and the impact of location on rental costs. Key objectives include:

Key objectives include:

  • Identifying affordable and premium areas
  • Analyzing host activity (single vs. multiple listings)
  • Understanding room type preferences
  • Exploring seasonal availability trends

Recommended Analysis

  • What is the average price per borough?
  • How does availability vary across neighborhoods?
  • Which room types are most common?
  • How do prices change based on room type and location?
  • What is the impact of host activity on pricing?

Data Understanding

Dataset: Airbnb NYC 2019 listings dataset

  • File Type: CSV
  • Records: 48,895 listings
  • Fields: 16 columns
  • Time Span: 2019

Data Structure

Field Description
idUnique listing ID
nameListing name
host_idHost ID
host_nameHost name
neighbourhood_groupNYC borough (Manhattan, Brooklyn, etc.)
neighbourhoodSpecific neighborhood name
latitudeGeographical latitude
longitudeGeographical longitude
room_typeListing type (Entire home, Private room, etc.)
pricePrice per night
minimum_nightsMinimum nights required for booking
number_of_reviewsTotal reviews for the listing
last_reviewDate of the last review
reviews_per_monthAverage monthly reviews
calculated_host_listings_countNumber of listings per host
availability_365Available days in a year

Data Preparation

Data Cleaning & Transformation in Tableau:

  • Removed duplicate and incomplete records
  • Converted price and reviews_per_month into numeric fields
  • Filtered out outliers (extremely high/low prices)
  • Categorized neighbourhood groups for easy analysis

Tableau Dashboard Creation

Key Visualizations in Tableau:

  1. Map of Listings (Geospatial Analysis)
    • Used latitude & longitude to plot listings
    • Applied color coding for neighbourhood_group
    • Adjusted size based on price
  2. Price Comparison by Borough (Bar Chart)
    • neighbourhood_group on the X-axis
    • AVG(price) on the Y-axis
    • Sorted in descending order
  3. Availability Trends (Line Chart)
    • Tracked availability_365 over time
    • Compared across boroughs
  4. Room Type Distribution (Pie Chart)
    • Showed % share of different room_type
    • Highlighted most common listing types

Dashboard Overview

The interactive Tableau Dashboard allows users to:

  • Explore pricing trends across NYC
  • Identify neighborhoods with the most listings
  • Compare room type availability
  • Analyze host activity and listing density

Key Insights

Listing Distribution
  • Manhattan has the highest number of Airbnb listings.
  • Brooklyn follows with a significant share.
Price Trends
  • Manhattan listings are the most expensive on average.
  • Queens and Bronx offer more budget-friendly options.
Room Type Analysis
  • Entire homes are priced significantly higher than private rooms.
  • Shared rooms are the least common and cheapest.
Availability & Host Activity
  • Many hosts manage multiple listings, indicating commercial use.
  • Listings with high availability tend to have lower review counts.
